Chrome Extension Privacy

Your bookmarks stay in Chrome.

BarShift works with your existing Chrome bookmarks to organize and switch bookmark bar profiles. It does not run its own server, does not use analytics or ads, and does not send your bookmark data to the developer.

1. Data BarShift accesses

Access

BarShift reads and modifies Chrome bookmarks only to provide its user-facing bookmark profile switching and page-saving features. This can include bookmark names, URLs, folder structure and related bookmark metadata.

When the user opens or explicitly invokes BarShift, the extension can temporarily access the current tab URL and title so that the user can save that page to a selected bookmark profile. BarShift does not read the contents of the web page.

BarShift stores limited configuration data in Chrome extension storage, including the active profile name, profile icons, colors, descriptions, pinned or hidden state, display settings, profile ordering, the previously used profile and temporary transaction-recovery state.

2. Purpose of data use

Purpose

The data described above is used only to provide BarShift's single purpose: organizing, switching and managing bookmark bar profiles and saving pages to those profiles.

3. Data transmission and sharing

Sharing

BarShift does not transmit bookmark contents, URLs, titles or BarShift settings to the developer or to third parties.

BarShift has no developer-operated external servers, analytics, advertising, tracking SDKs or remotely hosted executable code.

BarShift does not sell user data. BarShift does not use user data for advertising, profiling, creditworthiness or purposes unrelated to the extension's user-facing functionality.

4. Chrome Sync

Sync

Bookmark contents remain ordinary Chrome bookmarks. If the user has Chrome Sync enabled for bookmarks, Google Chrome may synchronize those bookmarks according to the user's Chrome settings. BarShift configuration stored through Chrome extension storage may also be synchronized by Chrome where supported.

This synchronization is provided by Google Chrome, not by a BarShift server. Google's processing of Chrome Sync data is governed by Google's own privacy terms and settings. BarShift does not control Google's processing of Chrome Sync data.

5. Right-click menu

Feature

If enabled, BarShift adds a browser context-menu entry that lets the user save the current page directly to a selected visible profile. This happens only after an explicit user action.

6. Data retention and user control

Control

BarShift does not retain user data on developer-controlled servers.

BarShift configuration is stored in Chrome extension storage and can be reset from BarShift's settings. Bookmarks remain under the user's control in Chrome and can be modified or deleted using Chrome's normal bookmark management tools. Removing BarShift does not create a separate developer-held copy of bookmark data.

7. Limited Use

Policy

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

8. Contact

Support

For privacy or support questions regarding BarShift, contact barshift.support@gmail.com.
